# SEA Games Manager

Tugas besar Algoritma Pemrograman. Aplikasi CLI untuk mengelola data negara peserta dan perolehan medali SEA Games, dibuat dengan Go.

## Fitur

- Tambah, ubah nama, dan hapus negara
- Update jumlah medali (emas, perak, perunggu)
- Tampilkan klasemen (urut emas, lalu perak, lalu perunggu)
- Cari negara dengan binary search
- Cari negara dengan total medali terbanyak

## Cara menjalankan

```
go run main.go
```

## Konsep yang dipakai

- Struct dan array statis
- Sequential search dan binary search (rekursif)
- Selection sort dan insertion sort
